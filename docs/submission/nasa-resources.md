## Lead resource: General Mission Analysis Tool (GMAT)

**Challenge entry:** [General Mission Analysis Tool (GMAT)](https://software.nasa.gov/software/GSC-19468-1) (NASA Software Catalog **GSC-19468-1**). The [Athlone Local Event organizer's challenge page](https://hackathlone.com/challenges/space-mission-design-game) lists it under NASA data and resources. The global [Details](https://www.spaceappschallenge.org/2026/challenges/space-mission-design-game/) and [Resources](https://www.spaceappschallenge.org/2026/challenges/space-mission-design-game/?tab=resources) URLs failed to load on this check. The NASA Catalog identifies the software family; its R2025a label is not the version we ran. [ESTABLISHED: https://hackathlone.com/challenges/space-mission-design-game, https://software.nasa.gov/software/GSC-19468-1]

**Actual use (GM01–GM04):** 1D used **GMAT R2026a** (GM04) to propagate four planar point-mass Earth cases: circular, eccentric, hyperbolic flyby, and a finite prograde burn followed by coast. GM01 informed the propagator/force/report setup and stop handling, GM02 supplied GMAT's Earth constants, and GM03 informed the finite-burn script. [DEMONSTRATED: `tools/gmat/`, `tests/vectors/gmat/`, and the recorded repeat-run checks in `docs/verification/gmat.md`.] The outputs are reference data created with a NASA tool. They are simulations, not observations from a real mission.

**How the data changed verification:** 2A checks each sampled state from the game's own fixed-step simulator against those reference vectors, including the burn's mass change. Across the four cases the recorded maxima are **0.022 m** and **1.8 × 10⁻⁵ m/s** at **6.25–25 ms** test steps. See [methods and submission paragraph](../verification/gmat.md#submission-paragraph), [test](../../src/sim/gmat.test.ts), and [P17/D4](../DECISIONS.md). [DEMONSTRATED: `src/sim/gmat.test.ts` (2A).] This is ordinary gravity and idealized propulsion verification at the stated test steps. It does not verify the separate belief-side estimator/issue path, the one-second play step at Earth-orbit scale, the fictional inverse-2.5 world or any playable route. Do not describe GMAT as running in the game. A1 predates the completed 2A comparison; cite D4 for the result.

**Global Award position:** GO Team requires meaningful use of at least one NASA data source listed for the selected challenge and also describes it as a NASA resource. GMAT is named in the local organizer's list, and its numerical outputs directly check the game code. [ESTABLISHED: https://github.com/nasa/spaceapps/discussions/1827, https://github.com/nasa/spaceapps/discussions/1849, https://hackathlone.com/challenges/space-mission-design-game] **[ASSUMED] This is a strong basis for the NASA-use requirement**, not an award ruling.

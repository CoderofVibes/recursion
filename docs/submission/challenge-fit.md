The core ask is a playable game in which people design, manage and simulate a complete space mission, make decisions under resource constraints, and see how those decisions change outcomes. Recursion starts aboard an existing ship after the original Mars mission. Its strongest interpretation is a **complete return mission redesigned in flight**: set mission criteria, choose a configuration and trajectory, fly, analyze the outcome, and revise. A title card alone will not close the design gap; the player must make a real plan with a downstream consequence.

Status reflects `p5/5c-submission` at `3f34484`, not parallel worktrees. **Gap** means missing from this scope, **Partial** means only part is specified or landed, and **Planned** means specified for a build lane but not established in play.

# Selections

The owner's chosen MidJourney images and why, for the builders and for the AI-use disclosure. **Images are references only** (DECISIONS A23): none ships, none is committed, and the game draws every view itself. This file holds no image files, only the record.

For the disclosure: MidJourney was used to make reference images that guided the procedural window views. No MidJourney output appears in the game.

**Job ID** is MidJourney's job UUID from the downloaded file name; **#** is the image's position in that job's grid (0–3). The owner keeps the files outside the repository (their Downloads folder, file names start `myvision_12_`).

**Verdicts:** *chosen* means the builders use the whole look. *Partial* means use only the named part. *Dropped* means don't use it.

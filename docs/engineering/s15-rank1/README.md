# S15 rank 1: evidence for the ship's per-tick cut

Thread 2G, 2026-11-14 PST. Before is `main` at `393b5a8`; after is `bdb9f5b`. The write-up is in `docs/handoffs/2G.md` § S15 rank 1.

- `tape-before.json`, `tape-after.json`: the command tape's fingerprint (`src/game/command-tape.test.ts`) for each start (nominal, worn, eclipse). `chain` is a SHA-256 over every tick's truth state, measurements and events in order, with −0 and non-finite numbers kept distinct; `totals` are readable end values. The two files are identical in every field. The per-tick hashes were compared tick by tick when they were made (the test fails at the first tick that differs) and are left out here for size.
- `node-bench-alternated.csv`: the ship step and the whole truth tick in µs, old and new code bundled and run alternately in Node, 2,000 ticks a run, best of 4 repeats inside each run, eight runs each (`mode` coast is S15's fixture: arrival commands only; tape is the command tape).
- `before/`, `after/`: S15's runner output (`tools/studies/s15/measure.mjs --phase frames --profiles modest --warps 2000 --repeats 1`), rounds `2g-r1` and `2g-r2`, alternated before, after, before, after. Each JSON has the source commit and tree hashes, the bundle hashes and every trial's summary; the `.json.gz` has every frame interval. CPU load from other sessions at the start of each run: 7%, 27%, 94%, 62%. `2g-r1.json` also holds S15's CPU-profile phase for the room view at 2000× (`--phase profile --profile-case modest:room:2000 --profile-label room`): the main thread's source-mapped self time per function. `node docs/engineering/s15-rank1/profile-groups.mjs` groups it by folder and per tick.

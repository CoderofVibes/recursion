### Open questions and uncertainty
- **Screen layout and how much of the compartment the player sees** — the owner's next big look-and-feel decision. Decides: owner, with 2D/2E. The theme does not depend on it.
- **Coverage history.** `ViewSnapshot.coverage` has only current sectors. "Sensed earlier" and "known from an earlier attempt" (§ 6.2) need history: 2E can accumulate current sectors itself within an attempt, but earlier attempts' coverage would need Black Box data in the snapshot. Decides: integrator.
- **Ship symbol at true scale in hazards** (§ 6.3): when exactly the enlargement switches off is 2E's call; the rule is that clearance is judged at true scale.
- **Font:** system Cascadia Mono. A bundled open font (e.g. an OFL monospace) would make the look identical on macOS and Linux; that needs a download and the owner's OK.

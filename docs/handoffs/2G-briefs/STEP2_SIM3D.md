## What to build
1. **Translation in 3D:** positions, velocities, gravity sum, the mutually moving bodies, asteroids, thrust, field accelerations and thrust modification, specific force (body frame, three components), asteroid absorption, closing-rate logic, validation (3D distances).
2. **Rigid-body attitude:** state is the unit quaternion q (body → inertial) and the body-frame angular velocity ω; inertia is `MassProperties.inertia = { moments, axes }` (principal moments and the rotation from the principal frame to the body frame). Torque = Σ (point − com) × force + the pure torque vector, all body frame. Integrate deterministically with a second-order, time-symmetric scheme that fits the existing kick–drift–kick step. The lead's recommendation, which you should use unless you find a concrete problem with it: **split the free rigid body in the principal frame into three exact rotations** (the angular-momentum splitting of McLachlan and Reich, also used by Touma and Wisdom and by Dullweber, Leimkuhler and McLachlan): with L = I·ω in the principal frame, the kinetic energy is Σ Lᵢ²/(2Iᵢ), and the flow of each term is an exact rotation of L about principal axis i by the angle (Lᵢ/Iᵢ)·τ together with the matching rotation of the attitude. A symmetric composition (x for dt/2, y for dt/2, z for dt, y for dt/2, x for dt/2) is second order, time-reversible, keeps |L| and the quaternion norm exactly (to rounding), and has no secular energy drift. Torque enters as half-step kicks of L at the start and end of the step, like the translational kicks (a torque that is constant in the body frame is the same vector at both ends). For rotation about a principal z axis this reduces exactly to the current planar scheme (θ += ω·dt; constant torque integrated exactly). Thrust stays constant in the body frame during a step and is rotated with q at the start and with q at the end (the trapezoid rule for the turning direction), as now. Mass properties are constant within a step, as now; the state keeps ω (not L) between steps, as now, and say in the README what that means when inertia changes between steps. Renormalise the quaternion only if needed and say so. **Report the scheme, why, and the measured drift** of rotational energy and of the inertial angular-momentum vector over long torque-free runs (axisymmetric and triaxial bodies, rates up to 0.05 rad/s, dt = 1 s and smaller), and show second-order convergence.
3. **Hull contact in 3D:** the hull is `MassProperties.hull`, a union of convex prisms (`HullPrism`: convex outline in body x–y, extruded from `zMin` to `zMax`); bodies and asteroids are spheres. Clearance is hull-to-surface. Work in the body frame as now (the object's centre moves along a straight segment in the body frame over a step).
   - Distance from a point to a prism is exact: with d₂ the signed 2D distance to the outline (existing code) and d_z = max(zMin − z, z − zMax), the distance is d₂ when d_z ≤ 0 < d₂, d_z when d₂ ≤ 0 < d_z, hypot(d₂, d_z) when both are positive, and max(d₂, d_z) (negative, inside) when both are ≤ 0. The closest hull point and the outward normal follow from the same cases.
   - Minimum clearance and the swept contact time along the segment: when the whole segment lies inside the prism's slab (zMin ≤ z ≤ zMax at both ends), the 3D problem is exactly the 2D one, so **use the existing exact `segmentPolygon` / `sweepPolygon` code path there**; that keeps every existing planar contact test bit-identical. Otherwise use the fact that the distance to a convex set is a convex function along a line: find the minimum with a fixed-count golden-section or ternary search, and the first crossing of the object's radius by a fixed-count bisection between the start and the minimum. Fixed iteration counts keep it deterministic. Take the minimum over prisms.
   - Contact response in 3D: the object is immovable; impulse j = (1 + e)·uₙ / (1/m + n·((I⁻¹(r × n)) × r)) along the contact normal with the full inertia tensor, Δv = −(j/m)·n, Δω = −I⁻¹(r × (j·n)), consistently in one frame; it must reduce to the current planar formula when everything is in the plane and z is a principal axis. Keep the existing behaviours: place the ship touching the surface, resting contact without repeated impact events, the 1 mm release slop, one clearance event per pass (also for a tumbling hull), the far-field shortcut measured from the centre of mass, and contact impulses appearing in the specific force.
   - Hull radius: `hullReach(hull, centerOfMass)` from the contracts.

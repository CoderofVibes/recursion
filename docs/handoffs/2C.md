## Open questions and uncertainty

- **Asteroids are absent from forecasts.** The model tracks massive bodies only, so `objects` and `closestApproaches` cover bodies, not asteroids. 1G specified asteroid tracking as an option (spec §10) without vectors. The brief's "predicted movement of nearby objects" and Gravity-range clearance will want it: fit each tracked asteroid as a test particle from its fixes and the ship's believed path, then propagate it under the believed law. 2F decides whether the first playable needs it.
- **Specified by 1G, not built:** unseen-body mode, region thrust response (Inverse Wells, Phase 3), outlier flags, sigma-point forecasts, pointing terms.
- **Several bodies at once:** a second body's windows and the present state use the other bodies frozen at their Tier G solution, as designed. The empirical-acceleration report with more than one modelled body freezes the other bodies from the first arc's solution, which is approximate for the other arcs. Only the single-body paths and the seen-body extension are vector-tested.
- **Sensor noise** in the vectors is 1G's placeholder. The model trusts each measurement's reported σ and widens envelopes by the noise scale s² when the data say σ is too small; retuning belongs to balance (2F, 5A).
- **Determinism** is bit-exact on one JavaScript engine (lib README); rebuild = live was shown in Node and the browser runs the same code.

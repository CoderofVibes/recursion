# Public research references

Start with BIBLIOGRAPHY.md for public source links and source-index.json for provenance and copy checksums.

The local-copies directory contains unchanged text extractions from 32 retained public references and 12 original PDFs. Topics include spacecraft power, thermal control, propulsion, navigation, communications, crew systems, reliability and physical constants. Additional public links provide standard mathematical and engineering references. Historical hardware examples and proposed instruments describe their published contexts, not a qualified spacecraft design.

Text extraction can omit equations, figures or formatting. Consult the linked original or local PDF when precision matters. Some older NASA Glenn links did not have a retained local copy; their listing does not assert current availability.

Local source copies are for research and are excluded from Git tracking by this directory's .gitignore. Cite the underlying publication when using its information. Check applicable terms before redistributing full documents, figures, data, software or other third-party assets. The bibliography does not grant blanket reuse rights.

This packet contains public references and general working preferences. Select and verify implementation assumptions during development; no spacecraft parameters, fictional laws, encounter solutions or game code are supplied here.

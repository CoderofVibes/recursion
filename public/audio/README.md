# Audio assets

**Every sound here is AI-generated.** The project owner made each one with ElevenLabs Sound Effects from a text prompt; the prompts are in [the cue list](../../docs/audio/cues.md). Each MP3's own tags say so too (artist and comment). The same holds for the trailer's sounds in `src/trailer/audio/`.

The files use the exact names in the cue list. Any subset is playable: a missing file is silence.
